This pack changes the textures of tridents to look unique when enchanted! Loyalty Tridents are Red and Riptide Tridents are Blue.

![A picture of the tridents being showcased in game.](https://cdn.modrinth.com/data/KVrXOftB/images/dcb7be79d5d0edee9331c3bb56474c7300a0c85b.png)

Due to technical limitations, (as far as I'm aware) it's impossible for the thrown loyalty trident to be accurate to the enchantment. If Mojang makes this possible in Vanilla, I'll consider adding it (this was already an headache to make and has been in development for multiple months lol)

Once again, unsurprisingly, I'm not the first person to make a pack like this! I found this pack after the fact that changes just the riptide model using what looks like the same method I used. Go check it out:
https://modrinth.com/resourcepack/riptide-trident
